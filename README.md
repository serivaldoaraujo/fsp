Este repositório contém os arquivos, dados e documentos gerados durante o desenvolvimento do artigo científico "Finanças Públicas, Ilusão Fiscal e Efeito Flypaper: Uma Análise Comparada entre os Polos Paulistas (Ribeirão Preto e Sorocaba) e o Quênia".

O projeto investiga a anomalia econômica conhecida como efeito flypaper (onde transferências governamentais estimulam mais gastos locais do que aumentos equivalentes na renda privada) e a ilusão fiscal no contexto do federalismo fiscal brasileiro, utilizando a teoria do Custo Marginal dos Fundos Públicos (MCF) de Dahlby (2011) e tendo como referência principal a tese de doutorado de Ferreira (UnB, 2021).

A pesquisa cruza a análise econométrica com uma revisão bibliométrica (utilizando o Bibliometrix / R-Tool com 100 artigos analisados), finalizando com uma comparação entre as economias subnacionais brasileiras de Ribeirão Preto e Sorocaba e o ambiente macroeconômico do Quênia.
